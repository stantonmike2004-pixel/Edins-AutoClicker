# Edins-AutoClicker

A lightweight, high-performance, and open-source auto-clicker built natively for Windows using C++ and the Win32 API.

![Windows](https://img.shields.io/badge/OS-Windows-blue)
![C++](https://img.shields.io/badge/Language-C%2B%2B-00599C)
![License](https://img.shields.io/badge/License-MIT-green)

---

## Features

- **Native Win32 GUI**: Clean, fast, and resource-friendly interface without heavy third-party dependencies.
- **Customizable Click Rates**: Set custom intervals between mouse clicks down to the millisecond.
- **Global Hotkeys**: Start and stop the auto-clicker anytime using quick keyboard shortcuts.
- **Low Overhead**: Built with pure C++ and MSVC for optimal efficiency and minimal CPU usage.

---

## Installation & Download

1. Go to the **[Actions](../../actions)** tab or **Releases** page of this repository.
2. Download the latest compiled `Edins_AutoClicker.exe`.
3. Double-click the executable to run—no installer required!
